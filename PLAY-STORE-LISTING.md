# Google Play — Store listing texts (Özüm üçün)

Paste these into **Play Console → Grow → Store presence → Main store listing**.
Play lets you add each language as a separate localized listing. Set **Azerbaijani**
as the default, then add English and Russian.

Limits: App name ≤ 30 chars · Short description ≤ 80 chars · Full description ≤ 4000 chars.

## ENGLISH

**Short description (≤ 80):**
`Self-discovery and the art of loving, guided by Erich Fromm. Calm and honest.`

**Full description:**
```
Özüm üçün ("for myself") is a philosophical companion for getting to know
yourself — without rushing. It draws on Erich Fromm's "The Art of Loving":
love is not a feeling you fall into, it is an art you practice.

No positivity slogans, no pressure, no fake motivation. Just calm, honest and
warm questions that help you be sincere with yourself.

WHAT'S INSIDE:
• 10 modules — care, responsibility, respect, knowledge, solitude, maturity and
  more, worked through step by step.
• Each module: a concept card → a reflection question → a daily practice → a
  scenario quiz.
• A private reflection journal — what you write stays only with you.
• A gentle progress system: a small heart grows as your journey grows.
• Optional daily reminders.
• 3 languages: Azerbaijani, English, Russian.

PRIVACY:
All your notes and progress are stored ONLY on your phone. No server, no sign-up,
no data collection. Works fully offline.

This app is not therapy, but a quiet place to begin understanding yourself better.
```

## RUSSIAN

**Short description (≤ 80):**
`Самопознание и искусство любить по Эриху Фромму. Спокойно и честно.`

**Full description:**
```
Özüm üçün («для себя») — философский спутник, чтобы без спешки узнать самого
себя. В основе — «Искусство любить» Эриха Фромма: любовь не чувство, в которое
падают, а искусство, которому учатся.

Здесь нет позитивных лозунгов, давления и фальшивой мотивации. Только спокойные,

ЧТО ВНУТРИ:

• Каждый модуль: карточка-концепт → вопрос для размышления → ежедневная

• Личный дневник размышлений — написанное остаётся только у тебя.
• Мягкая система прогресса: маленькое сердце растёт вместе с твоим путём.
• Ненавязчивые ежедневные напоминания (по желанию).
• 3 языка: азербайджанский, английский, русский.

КОНФИДЕНЦИАЛЬНОСТЬ:

регистрации, нет сбора данных. Работает полностью офлайн.

Это приложение не терапия, а тихое место, чтобы начать лучше понимать себя.
